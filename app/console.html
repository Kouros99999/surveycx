    Closed loop

    A low score opens an Amazon Connect Task with the answers and a link to the contact, so someone follows up while it matters.

    In the Connect console open the flow you want to receive the Tasks and copy the ID from its ARN (the part after contact-flow/).

    Written onto the contact when a survey completes, with surveycx_five, surveycx_nps, surveycx_ces and surveycx_low. Arena reads csat from contact records.

    Arena

    Send each agent-attributable score to Arena for Amazon Connect as CSAT_RECEIVED. In Arena, create an ingest key from the Data button and paste the site URL and key here.

    Verbatim analysis

    Sentiment on every free-text answer (Amazon Comprehend) and daily themes with example quotes (Amazon Bedrock). Emails, phone, card and account numbers are removed before any text is sent. Enabled with the stack's VerbatimAnalysis parameter.

    Brand

    Shown on the web survey and in emails. Leave the name empty to show "SurveyCX".

    Webhooks

    Every completed response is sent as JSON to these HTTPS URLs, signed with the secret (X-SurveyCX-Signature). Choose all responses or low scores only. Up to five; see the API reference in the help center.

    Other platforms and BI tools

    An ingest key lets Genesys, another platform or your middleware report finished contacts (POST /api/ingest/<key>/contacts) or answers collected elsewhere (/responses). A data key gives read-only access to responses for a warehouse (GET /api/data/<key>/responses?from&to). A key is shown once when created.

      Privacy requests
